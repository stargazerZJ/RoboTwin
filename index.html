Method (What we changed)

Motivation

End-to-end Visual-Language-Action (VLA) policies often fail in long-horizon tasks because early errors propagate and destabilize later stages.

Two-level hierarchy (minimal)

A high-level oracle outputs a subtask prompt; the low-level VLA policy executes actions conditioned on that prompt.

Subtask prompting

We evaluate both the baseline single prompt and an oracle split rubric that explicitly provides the current subtask instruction.

Subtask finetuning

We finetune the same low-level policy on data labeled with subtask prompts to strengthen subtask-aligned behaviors.
