## Enable GitHub Pages

On GitHub:

1. Go to **Settings → Pages**
2. **Build and deployment → Source**: “Deploy from a branch”
3. **Branch**: select `gh-pages` and “/ (root)”

That’s it — `index.html` is at repo root for direct GitHub Pages serving.
